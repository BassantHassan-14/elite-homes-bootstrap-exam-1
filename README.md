# 🏡 EliteHomes: Your Dream Home Awaits

A fully responsive real estate landing page built with **HTML, CSS, and Bootstrap**. It includes a mega-menu navbar, a property search form, featured listings, tabbed services, a testimonials carousel, an FAQ accordion, and a contact section.

## 🔗 Live Demo

👉 [View the live project](https://bassanthassan-14.github.io/elite-homes-bootstrap-exam-1/)

## ✨ Features

- 🧭 **Fixed navbar** with scroll-spy highlighting and an animated underline on links
- 📂 **Properties mega-menu** (featured properties, property types, popular locations, resources) that adapts to mobile
- 🔍 **Hero section** with a property search form (location, type, price, bedrooms, bathrooms, square footage) and key stats
- 🏠 **Featured properties** cards with badges (Featured, New Listing, Price Drop), favorite button, agent info, and a hover zoom effect
- 🗂️ **Services tabs**: Buying, Selling, Renting, Investing, Commercial
- 💬 **Testimonials carousel** with auto-play, indicators, and navigation arrows
- ❓ **FAQ accordion** with 7 common real estate questions
- 📞 **Contact section** with info cards, social links, and a message form
- 📱 Responsive design from mobile to large desktop

## 🛠️ Built With

- HTML5
- CSS3 (custom styles, gradients, pseudo-elements, transitions, media queries)
- Bootstrap 5 (grid, navbar, dropdown, tabs, carousel, accordion, scrollspy)
- Font Awesome
- Exo font
